## Precedural Art Style Transfer Generator

# Status:  Active Development and Feature Expansion
This project is a demonstrative MLOps pipeline showcasing the deployment of a real-time Deep Learning model as a scalable, containerized web service.

The primary goal is to validate the full machine learning lifecycle, from codebase debugging to scalable cloud deployment.

 Tech Stack
The application leverages a modern microservice architecture designed for scalability and maintainability:
Model:  PyTorch
API Layer:  FastAPI
Containerization:  Docker
Deployment:  GCP Cloud Run
